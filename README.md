# NotepadM

**NotepadM** — это начальный проект текстового редактора с расширенными возможностями, разработанный на Java. Проект полностью бесплатен и предназначен для обучения, экспериментов и развития навыков программирования.

## Особенности
- Простое и интуитивное управление.
- Расширяемая функциональность.
- Кроссплатформенность (работает на любой системе с установленной Java).
- Исходный код открыт для всех желающих.

## Цель проекта
NotepadM создаётся как первый проект автора, с целью изучения Java и разработки функционального текстового редактора. Проект открыт для совместной работы, и каждый может предложить идеи по улучшению и новым возможностям.
