# NotepadM

Кроссплатформенный текстовый редактор для Windows, Linux и macOS на **Rust + Slint**.

Проект начинался как Java-приложение (Swing, затем JavaFX) и переписан на Rust —
история этого пути сохранена в ветках репозитория и в журнале разработки
([docs/dev-log.md](docs/dev-log.md)).

## Возможности

- вкладки с признаком несохранённых изменений и защитой от потери данных
  (подтверждение при закрытии вкладки и выходе);
- поиск и замена (Ctrl+F / Ctrl+H): «Найти далее» с подсветкой и счётчиком
  вхождений, «Заменить», «Заменить все», учёт регистра (корректно для кириллицы);
- открытие файлов в любых кодировках (UTF-8, Windows-1251, …) с автоопределением;
  сохранение — в исходной кодировке файла;
- предпросмотр HTML в браузере по умолчанию;
- панель инструментов, меню и горячие клавиши
  (Ctrl+N/O/S, Ctrl+Shift+S, Ctrl+W, F3, Esc).

## Сборка и запуск

Нужен [Rust](https://rustup.rs) (стабильный канал):

```
cargo run                # сборка и запуск (debug)
cargo build --release    # оптимизированный бинарник: target/release/notepadm(.exe)
```

На Linux дополнительно: `sudo apt-get install libxkbcommon-dev libfontconfig1-dev`.

## Разработка

```
cargo test                    # юнит-тесты
cargo clippy -- -D warnings   # линтер
cargo fmt                     # форматирование
```

CI (GitHub Actions) собирает проект под Windows / Linux / macOS и гоняет
эти же проверки на каждый push в ветку `rust`.

Документация — в папке [docs/](docs/): журнал разработки с разбором решений
(dev-log.md), актуальная архитектура (architecture.md), план (todo.md).
Вся документация ведётся на русском языке.
