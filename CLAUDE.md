# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Язык

Пользователь общается по-русски. Отвечай на русском; вся документация проекта
(docs/, комментарии в коде, сообщения коммитов) — на русском языке.

## Команды

```
cargo run                # сборка и запуск (debug)
cargo build --release    # оптимизированный бинарник target/release/notepadm(.exe)
cargo test               # юнит-тесты (живут в src/main.rs, mod tests)
cargo test finds_all     # один тест по подстроке имени
cargo clippy -- -D warnings
cargo fmt                # обязательно перед коммитом: CI проверяет fmt --check
```

Первая сборка долгая (компилируется Slint); дальше — инкрементально.
На Linux для сборки нужны `libxkbcommon-dev libfontconfig1-dev`.

## Архитектура

Текстовый редактор на Rust + Slint. Актуальное описание — `docs/architecture.md`
(поддерживается в актуальном состоянии, читай его первым).

Ключевое:

- `ui/main.slint` — вся разметка окна (меню, тулбар, панель поиска, вкладки,
  редактор — свой компонент Editor на базе TextInput, строка состояния). `build.rs` компилирует её в Rust-код на этапе сборки
  (`slint_build::compile`), в `main.rs` он подключается через
  `slint::include_modules!()`. Ошибка в разметке = ошибка компиляции.
- `src/main.rs` — весь Rust-код: состояние и обработчики. Источник истины —
  `Rc<RefCell<Vec<Document>>>` (путь, текст, dirty, кодировка); UI получает
  производные данные через `VecModel<TabInfo>` и свойства. Исключение: текст
  активной вкладки живёт в UI-свойстве и списывается в `Document` лениво
  (`sync_active_doc` в точках синхронизации — не на каждое нажатие).
  Направления связи: callbacks (UI → Rust), свойства и `invoke_*` публичных
  функций (Rust → UI).
- Иконки в `ui/images/` встраиваются в бинарник через `@image-url`.
- Кодировки: файлы читаются как байты + автоопределение (`decode_bytes`:
  UTF-8 → chardetng), сохранение — в исходной кодировке документа.
- Горячие клавиши — `FocusScope` в разметке: непойманные редактором нажатия
  всплывают к нему.

## Соглашения проекта

- `docs/dev-log.md` — журнал-учебник, только дополняется. На каждый значимый шаг —
  запись: что сделано, как, почему; новые конструкции Rust объясняются с аналогиями
  из Java (пользователь изучает Rust по этому журналу). Не превращать в changelog.
- `docs/architecture.md` — актуальное состояние, перезаписывается при изменениях.
- `docs/todo.md` — план; выполненное помечать `[x]` со ссылкой на запись dev-log.
- Коммиты — только по явной команде пользователя («зафиксируй»); документация
  коммитится вместе с кодом, который она описывает.
- Ветки: `rust` — текущая (Rust), `dev` — JavaFX, `master` — Swing. Java-ветки
  не трогать; файлы Java-версии при необходимости доставать из истории
  (`git show master:путь`).
- Push на GitHub — отложен, только по явной команде.
