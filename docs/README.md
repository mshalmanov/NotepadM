# Документация NotepadM

Вся документация проекта ведётся в этой папке, на русском языке.

| Файл | Содержание |
|---|---|
| [dev-log.md](dev-log.md) | Журнал разработки + учебник: каждая запись объясняет сделанные изменения, конструкции Rust и выбранные технологии |
| [architecture.md](architecture.md) | Текущая архитектура приложения: структура, поток данных, соглашения |
| [todo.md](todo.md) | План развития: очередь задач с разбивкой на подпункты |

## Правила ведения

- **dev-log.md** пополняется записью на каждый значимый шаг разработки. Запись отвечает
  на три вопроса: что сделано, как работает, почему так. Новые конструкции языка
  объясняются при первом появлении, по возможности через аналогии с Java.
- **architecture.md** отражает актуальное состояние (перезаписывается), в отличие от
  dev-log, который только дополняется.
