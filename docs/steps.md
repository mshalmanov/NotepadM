# Журнал выполненных шагов

Пошаговая история изменений проекта, внесённых в ходе работы с ассистентом.
Формат каждой записи: **Задача** → полное описание → дата. Добавляйте новые
записи в конец файла по мере выполнения работы, чтобы можно было отследить
историю решений отдельно от git-лога.

---

### 1. Первичный код-ревью проекта

**Описание:** Проведён полный анализ структуры проекта NotepadM (JavaFX-редактор
на Maven). Выявлены: мёртвый код от старой Swing-версии (`src/MainForm.java`,
`src/main/java/MainForm.java`, `src/META-INF/MANIFEST.MF`), опечатка в имени
поля контроллера (`pastMenuItem` вместо `pasteMenuItem`), девять `ImageView` в
`MainForm.fxml` с одинаковым `fx:id="openIcon"`, рассинхронизация версии Java
между `pom.xml` (11), `launch4j` (17) и CI (17), закоммиченный `NotepadM.iml`
при наличии правила в `.gitignore`. Предложен приоритизированный план
исправлений.

**Дата:** 2026-08-27

---

### 2. Удаление мёртвого Swing-кода

**Описание:** Удалены файлы старой реализации на Swing, оставшиеся после
миграции на JavaFX+FXML: `src/MainForm.java`, `src/main/java/MainForm.java`,
`src/META-INF/MANIFEST.MF`. Файлы нигде не использовались в сборке и содержали
неработающие относительные пути к иконкам (`src/images/...`). Зафиксировано
коммитом `94a3fe2` ("remove: удалён мёртвый код старой Swing-версии
редактора").

**Дата:** 2026-08-27

---

### 3. Исправление рассинхронизации FXML ↔ контроллер

**Описание:** В `MainFormController.java` поле `pastMenuItem` переименовано в
`pasteMenuItem` в соответствии с `fx:id` в `MainForm.fxml` — иначе
`@FXML`-инъекция для этого поля не срабатывала бы. В `MainForm.fxml` девяти
разным `ImageView` в тулбаре присвоены уникальные `fx:id` (`newIcon`,
`saveIcon`, `cutIcon`, `copyIcon`, `pasteIcon`, `boldIcon`, `italicsIcon`,
`underlineIcon`) вместо одинакового `openIcon` — дубликаты были валидны только
потому, что поля не объявлены в контроллере, и привели бы к `LoadException`
при первом обращении к ним. Зафиксировано коммитом `dcb9ba2` ("fix: устранены
рассинхронизации между FXML и контроллером").

**Дата:** 2026-08-27

### 4. Настройка окружения сборки (JDK 21 + Maven)

**Описание:** На машине разработчика изначально отсутствовали JDK и Maven.
Пользователь установил Oracle JDK 21 (`C:\Program Files\Java\jdk-21.0.12.1`).
Apache Maven 3.9.16 был скачан вручную с официального CDN Apache
(`dlcdn.apache.org`), распакован и впоследствии перемещён пользователем в
`%LOCALAPPDATA%\maven`. Проверена корректность связки командой `mvn -v`.

**Дата:** 2026-08-27

---

### 5. Унификация версии Java на 21

**Описание:** `pom.xml`: `maven.compiler.source`/`maven.compiler.target`
изменены с `17` на `21`; `launch4j.jre.minVersion` изменён с `17` на `21`.
`.github/workflows/main.yml`: `actions/setup-java` обновлён на JDK `21`.
Теперь версия компиляции, требование к JRE в упакованном `.exe` и версия JDK
в CI согласованы между собой и с установленной на машине JDK. Зафиксировано
коммитом `b7f8407` ("build: унифицирована версия Java на 21").

**Дата:** 2026-08-27

`launch.json` (запуск/отладка `ru.filive.MainForm` в classpath-режиме — без

### 7. Сборка и проверка запуска проекта

**Описание:** Выполнены `mvn clean test` (тестов в проекте нет — "No tests to
run", сборка прошла успешно) и `mvn clean install` (полная сборка: компиляция,
упаковка fat-jar через `maven-shade-plugin`, упаковка `NotepadM.exe` через
`launch4j-maven-plugin` — `BUILD SUCCESS`). Прямой запуск шейдед-jar
(`java -jar target/NotepadM-1.0-SNAPSHOT.jar`) завершился без исключений
(только предупреждение JavaFX про unnamed module — ожидаемо для fat-jar без
`module-info.java`). Визуальная проверка отрисовки окна не выполнена — среда
выполнения ассистента не имеет доступа к рабочему столу/скриншотам для
нативных Win32 GUI-приложений; рекомендовано пользователю проверить вручную.

**Дата:** 2026-08-27

### 8. Код-ревью для рефакторинга/оптимизации (без применения правок)

**Описание:** По запросу на рефакторинг и оптимизацию кода составлен список
из 14 находок по `MainFormController.java`, `MainForm.fxml` и `MainForm.java`:
избыточная ручная реализация `Copy` вместо встроенного `TextArea.copy()`,
пустые заглушки `Cut`/`Paste`, нерабочий `Exit` (не закрывает приложение),
фиктивные `Open`/`Save`, неиспользуемые `@FXML`-поля меню, отсутствие
уникальных имён вкладок, архитектурная невозможность Bold/Italic/Underline на
`TextArea`, опечатка `text="Open"` у пункта меню "New", вводящий в заблуждение
комментарий-"конструктор" над `Application.start()`, остатки закомментированного
Swing-кода, отсутствие тестов. По решению пользователя правки не применялись —
список сохранён как основа для `docs/todo.md`.

**Дата:** 2026-08-27
